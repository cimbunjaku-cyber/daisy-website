# Daisy website

A responsive, single-page English marketing site for Daisy. Open `index.html` in a browser to preview it. The original Daisy wordmark is included at `daisy-logo.jpg`.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder.
2. In **Settings → Pages**, choose the `main` branch and the repository root as the publishing source.
3. For `daisy-ks.com`, add the custom domain in Pages settings, then configure the DNS records GitHub specifies with the domain provider. Enable **Enforce HTTPS** when the certificate is ready.

## Confirm before publishing

- `hello@daisy-ks.com` is a proposed contact address used by the contact button and footer. Replace it in `index.html` if Daisy uses a different address.
- The service descriptions are proposed marketing-agency copy. Confirm they match Daisy's actual services.
- Add Daisy's real social links and portfolio if you want them displayed.
